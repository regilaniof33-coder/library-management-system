# Library Management System

A simple library management system developed in Java as an academic project for my Analysis and Systems Development course.

The project was created to practice fundamental Object-Oriented Programming concepts and basic data management.

## Features

* Register books
* Register readers
* Search for books by ID
* Search for readers
* Borrow books
* Return books
* Display library information

## Concepts Practiced

* Object-Oriented Programming (OOP)
* Classes and objects
* Constructors
* Arrays
* Methods
* Encapsulation
* `if/else` statements
* `for` and `do-while` loops
* `switch/case`
* Java `Scanner`
* Basic object manipulation

## Technologies

* Java
* IntelliJ IDEA / VS Code

## Project Structure

```text
src/
├── Main.java
├── Livro.java
└── Leitor.java
```

### Main

Responsible for the program flow, menu, user input, and library operations.

### Livro

Represents a book and stores information such as ID, title, author, status, and borrower.

### Leitor

Represents a library reader and stores the reader's information.

## About the Project

This project was developed as part of my studies in Analysis and Systems Development (ADS) at IFCE.

It represents one of my early projects using Java and Object-Oriented Programming.
